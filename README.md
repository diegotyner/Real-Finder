# Real-Finder

A personal utility for quickly indexing and searching the Jazz Real Book

### Working:

A minimal finder for songs in the real book. Simply open up the finder.html file and search for songs by entering queries into the input text area.

### Future:

Hopefully a more complete finder with options to search for composer, feel/genre, etc. This requires me to get the OCR working WELL though, a lot of future work needed for that.
